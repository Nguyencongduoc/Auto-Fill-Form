AUTO FILL FORM v0.5.0 — CÀI NHANH TRÊN CHROME

YÊU CẦU: Chrome 116+. Không cần Node.js, build, tài khoản AI hoặc CRX để dùng.

CÀI MỚI
1. Tải mã nguồn từ GitHub và giải nén, hoặc clone repository.
2. Mở chrome://extensions, bật Developer mode.
3. Load unpacked → chọn thư mục extension trong mã nguồn.
   Thư mục được chọn phải chứa trực tiếp manifest.json.
4. Nếu dùng auto-fill-form-0.5.0.zip do script đóng gói tạo ra, chọn CHÍNH
   thư mục vừa giải nén vì manifest đã ở gốc.
5. Xác nhận quyền LMS HUST nếu Chrome yêu cầu, rồi ghim tiện ích.
6. Không chọn Pack extension. Giữ nguyên thư mục sau khi nạp.

CẬP NHẬT
Xuất JSON riêng để sao lưu, dừng tự chạy, thay file trong cùng thư mục đã nạp,
bấm Reload trên thẻ tiện ích và tải lại tab câu hỏi. Nạp từ đường dẫn khác có
thể tạo ID khác; cần nhập lại JSON đã xuất. Gỡ tiện ích sẽ xóa dữ liệu của nó.

TỰ CHẠY LMS
Đăng nhập → mở lượt làm bài attempt.php → bấm biểu tượng extension → chọn bộ
JSON hoặc Nạp đáp án CNPM · 351 câu → kiểm tra → Bắt đầu tự chạy.
Tiện ích quét/điền/xác minh/Next. Câu thiếu hoặc mơ hồ: nhập trong bảng bên,
bổ sung đủ rồi Tiếp tục. Câu chưa hỗ trợ: xử lý trên LMS và bật xác nhận.
Có Tạm dừng/Dừng. Trang cuối được giữ lại để bạn tự kiểm tra và nộp bài.
Đóng bảng bên/chuyển tab khác không dừng phiên ở tab LMS đã chọn; đóng tab
hoặc Chrome kết thúc phiên. Next chưa chuyển/tải xong sau 15 giây sẽ tạm dừng.
Một Next đã gửi vẫn có thể tải xong sau khi bấm Tạm dừng/Dừng.
Đáp án bổ sung không tự ghi vào JSON; lưu/chỉnh bộ riêng để giữ lâu dài.

MICROSOFT FORMS
ResponsePage.aspx → biểu tượng extension → chọn/nhập JSON → kiểm tra → Điền.
Tự chuyển phần nếu cần; không có tự Next trên Forms. ResponseDetailPage.aspx
là trang kết quả chỉ đọc. Bộ 200 câu Quy chế tự chọn khi ID form khớp.

QUYỀN VÀ KIỂM CHỨNG
Quyền thường trực chỉ cho https://lms.hust.edu.vn/* để đọc trang sau Next.
Forms dùng activeTab. Website có thể tự lưu; Next LMS gửi biểu mẫu trang.
Tiện ích không bấm Finish/nút nộp cuối. Đã thử fixture Chrome, chưa xác nhận
điền trên phiên thật đã đăng nhập. Hoàn tác chỉ giữ lần điền gần nhất trên
tài liệu/trang hiện tại, không khôi phục các trang đã chuyển.

DEMO: Thử tính năng bằng bản demo → Quét → nhập examples/demo-answers.json
→ Điền 3 câu → Hoàn tác.
